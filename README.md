# controle_de_despesas
💰 Controle de Despesas Pessoais

Sistema web desenvolvido para auxiliar no gerenciamento e na organização das despesas pessoais, permitindo registrar, visualizar, editar e excluir gastos de maneira simples e intuitiva.

O projeto tem como finalidade facilitar o controle financeiro, oferecendo uma visão geral dos gastos e permitindo acompanhar o dinheiro utilizado em diferentes categorias.

📌 Sobre o Projeto

O Controle de Despesas Pessoais é uma aplicação web desenvolvida utilizando HTML5, CSS3 e JavaScript.

A aplicação permite que o usuário registre suas despesas, informe seus respectivos valores, categorias e datas, além de acompanhar automaticamente o total de gastos cadastrados.

Os dados são armazenados localmente no navegador por meio do LocalStorage, garantindo que as informações permaneçam salvas mesmo após o fechamento da página.

🎯 Objetivo Geral

Desenvolver uma aplicação web simples e intuitiva que ajude os usuários a organizar suas finanças pessoais, controlar seus gastos e acompanhar suas despesas de forma prática.

⚙️ Funcionalidades

O sistema contará com as seguintes funcionalidades:

Cadastro de despesas: adicionar novas despesas informando nome, valor, categoria e data.
Listagem de despesas: visualizar todas as despesas cadastradas.
Edição de despesas: modificar as informações de despesas existentes.
Exclusão de despesas: remover registros cadastrados.
Cálculo automático: calcular o valor total de todas as despesas.
Organização por categorias: separar os gastos conforme suas categorias.
Armazenamento local: salvar os dados utilizando LocalStorage.
Validação de formulário: verificar se os dados informados estão corretos antes do cadastro.

🖥️ Estrutura da Aplicação

A interface será organizada em áreas principais:

Cabeçalho: identificação do sistema com o nome Controle de Despesas.
Painel financeiro: apresentação do valor total das despesas cadastradas.
Formulário: campos para adicionar novas despesas.
Histórico de despesas: tabela ou lista com os registros realizados.
Gerenciamento: opções para editar e excluir despesas.
Resumo por categorias: visualização dos gastos separados por categoria.
